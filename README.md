## Features

- Compare files, folders, or zip archives — side-by-side or unified diff view
- Categorized results: All · Modified · Added · Deleted · Unchanged
- Line-level diff highlighting with change block navigation ("Go to Line")
- Search within diffs, filter files by name
- Split view and line wrapping toggles, zoom in/out
- Export diffs as:
  - **Unified Diff** (`.diff`) — compatible with git, IDEs, code editors
  - **Stock vs Modified report** (`.txt`) — readable side-by-side line report
- 9 built-in themes — Compare Slate, Midnight Indigo, Forest Green, Sunset Amber, Ocean Cyan, Sakura Rose, Nordic Ice, Cosmic Purple, Vintage Sepia

> **Comparing APKs?** [MT Manager](https://mt2.cn) is recommended for direct APK comparison. Alternatively, decompile both source and modified APKs and compare the output with CompareKit.

## Usage

1. Open CompareKit
2. Tap **Pick Original Files/Folder** and select your source
3. Tap **Pick Modified Files/Folder** and select the changed version
4. Browse results by category (All / Modified / Added / Deleted / Unchanged)
5. Tap **Compare** on any file to view the detailed diff
6. Use the menu (⋮) to search, switch views, zoom, or export

## Supported Inputs

- Individual files
- Folders (recursive)
- Zip archives (`.zip`)
